# 产品总览

## 1. 产品工作名

`宠物生活管家`

## 2. 一句话定义

帮助养宠用户记录宠物档案、管理健康提醒、沉淀萌宠日常、参与社区互动，并连接本地服务，为智能硬件能力预留后续接入空间。

## 3. 产品定位

这不是一个简单的宠物社区，也不是一个单一健康工具，而是一个围绕 `宠物` 作为核心对象组织信息、内容和服务，并为设备数据预留位置的一站式养宠 App。

产品主线为：

`宠物档案 -> 健康/日常记录 -> 成长时间轴 -> 社区分享 -> 服务补充`

## 4. 当前阶段目标

当前阶段先不考虑商业化，优先追求：

1. 用户量增长
2. 建档率提升
3. 高频使用场景建立
4. 社区内容供给形成
5. 留存和回访习惯建立

## 4.1 当前实现范围

1. 当前以用户端 App、服务端和后台管理端同步推进完整交付范围。
2. 商城仅保留真实占位页和入口，不进入后端交易接口和订单链路。
3. 设备仅保留信息架构和技术预留，当前不接入设备厂商。
4. 运营、审核、服务商数据维护需要同步建设后台管理能力，但不扩成完整的全域运营平台。

## 5. 目标用户

### 5.1 核心用户

- 城市猫狗主人
- 新手养宠用户
- 养宠 0 到 3 年的人群
- 喜欢记录宠物生活和分享内容的用户

### 5.2 重要扩展用户

- 多宠家庭
- 家庭共养用户
- 对本地服务有强需求的用户
- 已购买宠物智能设备的用户

## 6. 核心用户问题

1. 宠物资料、疫苗、驱虫、体检和异常情况分散，无法统一管理。
2. 养宠日常没有沉淀，照片和视频散落在相册里，难以形成长期成长记录。
3. 宠物社区内容和实际养宠生活脱节，内容消费多，沉淀价值少。
4. 医院、洗护、寄养、训练、商品等服务入口零散，用户难以根据自己宠物快速决策。
5. 智能设备数据和宠物健康档案没有打通，设备只能控制，不能沉淀长期价值。

## 7. 完整态核心目标

1. 记录宠物完整数字档案
2. 管理疫苗、驱虫、体检、用药和异常观察
3. 记录萌宠日常与成长日记
4. 支持社区分享与互动
5. 支持宠物医院预约
6. 支持宠物商品购买
7. 支持寄养、洗护、训练等服务
8. 支持智能硬件联动
9. 支持家庭共养协同

## 8. 产品原则

### 8.1 宠物是主轴

所有记录、服务、内容、设备都应归属于具体宠物，而不是成为孤立模块。

### 8.2 高低频结合

- 高频靠 `萌宠日常`、`快捷记录`、`社区浏览`
- 低频但高价值靠 `健康档案`、`提醒计划`、`医院预约`

### 8.3 不做伪专业医疗

健康相关只做：

- 记录
- 提醒
- 异常观察
- 历史回看
- 导出辅助

不替代兽医诊断。

### 8.4 预留模块不做空白页

医院预约、商品购买、寄养洗护训练、智能硬件等暂未完全建设的模块，也必须以 `预留态页面` 承接，至少包含：

- 功能说明
- 开通状态
- 需求收集
- 开通通知
- 相关推荐入口

### 8.5 社区要服务主链路

社区不是独立世界，社区内容应与：

- 宠物卡片
- 萌宠日常
- 商品体验
- 服务体验
- 成长记录

发生联动。

## 9. 核心使用场景

### 9.1 首次建档

用户进入 App，创建宠物档案，配置提醒，建立第一只宠物的数字身份。

### 9.2 每日记录

用户通过快捷入口记录喂食、饮水、排便、体重，或补充一条萌宠日常。

### 9.3 萌宠成长沉淀

用户通过图文或视频记录宠物的可爱瞬间、纪念日、训练进展和生活趣事。

### 9.4 异常观察与就医前记录

用户记录症状、持续时间和严重程度，并查看历史观察情况，必要时进入医院预约。

### 9.5 社区分享与互动

用户将萌宠日常或经验内容发布到社区，获取点赞、评论和关注。

### 9.6 服务获取

用户根据当前宠物寻找医院、寄养、洗护、训练服务，或购买相关商品。
用户根据当前宠物寻找医院、寄养、洗护、训练服务。商城当前仅保留用户端占位页，不进入真实交易。

### 9.7 设备联动

设备联动作为完整态能力保留，当前阶段仅预留入口与技术边界，不接入设备厂商。

## 10. 核心主链路

### 10.1 建档链路

`登录 -> 创建宠物 -> 完善档案 -> 设置提醒 -> 进入首页`

### 10.2 高频使用链路

`首页 -> 快捷记录 / 记日常 -> 写入成长时间轴 -> 周报反馈`

### 10.3 分享链路

`萌宠日常 -> 公开 -> 社区发布 -> 获取互动 -> 回流宠物主页`

### 10.4 服务链路

`宠物主页 / 首页 -> 服务入口 -> 预约 / 查看预留页 -> 记录回看`

### 10.5 设备链路（完整态预留）

`设备绑定 -> 数据同步 -> 时间轴更新 -> 异常提醒`

## 11. 关键增长与留存点

1. 建档完成后立刻生成健康提醒和成长时间轴。
2. 首页提供极低成本的快捷记录和记日常入口。
3. 萌宠日常天然作为社区内容来源，降低发帖门槛。
4. 家庭共养让多名用户围绕同一只宠物重复回访。
5. 周报和月报强化长期价值感。

## 12. 核心指标

1. 宠物建档完成率
2. 新用户首日记录率
3. 7 日留存
4. 30 日留存
5. 萌宠日常发布率
6. 社区互动率
7. 家庭成员邀请率
8. 服务预约发起率
9. 首页快捷记录使用率

## 13. 当前开放问题

1. 产品品牌风格是偏工具、偏情感陪伴，还是偏年轻社区化。
2. 首页首屏优先强调 `待办任务` 还是 `萌宠日常`。
3. 社区同城内容是否需要与服务商家内容混排。
4. 商城占位页和设备预留页是否统一进入服务聚合页，而不单独占主导航。
