# 低保真线框说明

## 1. 首页驾驶舱

```text
+--------------------------------------------------+
| [城市]               [搜索]           [消息]      |
+--------------------------------------------------+
| 当前宠物卡：头像 / 名字 / 年龄 / 今日状态 / 切换  |
+--------------------------------------------------+
| 今日待办                                          |
| - 疫苗提醒                                        |
| - 驱虫提醒                                        |
| - 体检提醒                                        |
| - 自定义待办                                      |
+--------------------------------------------------+
| 快捷记录                                          |
| [喂食] [饮水] [排便] [体重] [用药] [记日常]       |
+--------------------------------------------------+
| 萌宠日常                                          |
| 最近一条记录 / 今天记录一下 TA                    |
+--------------------------------------------------+
| 社区推荐                                          |
| 内容卡片 1                                        |
| 内容卡片 2                                        |
+--------------------------------------------------+
| 服务入口                                          |
| [医院] [寄养] [洗护] [训练] [商城]                |
+--------------------------------------------------+
| 设备状态摘要                                      |
| 喂食器在线 / 饮水机正常 / 最近无异常              |
+--------------------------------------------------+
| [首页] [宠物] [社区] [服务] [我的]                |
+--------------------------------------------------+
```

### 设计说明

- 首页的首要任务是让用户快速完成一次行为，而不是只做信息展示。
- `今日待办` 与 `快捷记录` 必须处于首屏核心区域。
- `萌宠日常` 需要成为高频情感入口，不能只放在二级页面。

## 2. 宠物主页

```text
+--------------------------------------------------+
| [返回]               宠物主页             [切换]   |
+--------------------------------------------------+
| 宠物头图 / 名字 / 品种 / 年龄 / 基础标签          |
+--------------------------------------------------+
| 基础档案摘要                                      |
| 生日 / 到家日期 / 体重 / 绝育状态                 |
+--------------------------------------------------+
| 健康档案       | 提醒计划                         |
+--------------------------------------------------+
| 萌宠日常预览                                      |
| 最近照片 / 最近视频 / 快速新建                    |
+--------------------------------------------------+
| 成长时间轴入口                                    |
+--------------------------------------------------+
| 设备状态                                          |
| 在线设备数 / 异常提醒                             |
+--------------------------------------------------+
| 相关服务推荐                                      |
| 医院 / 洗护 / 寄养 / 训练 / 商品                  |
+--------------------------------------------------+
```

### 设计说明

- 宠物主页是宠物对象的总入口，不是单纯资料页。
- 健康、日常、设备、服务必须聚合在同一页面里建立全局感。

## 3. 萌宠日常列表页

```text
+--------------------------------------------------+
| [返回]             萌宠日常              [新建]    |
+--------------------------------------------------+
| [全部] [图片] [视频] [公开] [私密]                |
+--------------------------------------------------+
| 日常卡片                                          |
| 封面图                                            |
| 标题 / 标签 / 可见范围 / 时间                     |
+--------------------------------------------------+
| 日常卡片                                          |
| 封面图                                            |
| 标题 / 标签 / 可见范围 / 时间                     |
+--------------------------------------------------+
```

### 设计说明

- 列表页强调回看和筛选。
- 公开与私密状态必须明确标识，避免用户误发。

## 4. 萌宠日常新建页

```text
+--------------------------------------------------+
| [取消]             记录日常              [发布]    |
+--------------------------------------------------+
| 上传图片/视频                                     |
+--------------------------------------------------+
| 标题：______________________________              |
| 描述：______________________________              |
+--------------------------------------------------+
| 标签： [散步] [吃饭] [睡觉] [训练] [生日]         |
+--------------------------------------------------+
| 状态： [开心] [活跃] [粘人] [低落]                |
+--------------------------------------------------+
| 可见范围：                                        |
| ( ) 私密   ( ) 家庭可见   ( ) 公开                |
+--------------------------------------------------+
| [ ] 加入成长时间轴                                |
| [ ] 同步到社区                                    |
+--------------------------------------------------+
```

### 设计说明

- 表单必须轻量，不应要求过多字段。
- `同步到社区` 默认关闭，避免将“记录”变成“发帖压力”。

## 5. 社区首页

```text
+--------------------------------------------------+
| [搜索]                               [发布]       |
+--------------------------------------------------+
| [推荐] [关注] [同城] [问答]                        |
+--------------------------------------------------+
| 内容卡片                                          |
| 作者头像 / 昵称 / 宠物卡片                         |
| 图片或视频封面                                    |
| 标题摘要                                          |
| [点赞] [评论] [收藏]                              |
+--------------------------------------------------+
| 热门话题                                          |
+--------------------------------------------------+
| 同城内容推荐                                      |
+--------------------------------------------------+
| [首页] [宠物] [社区] [服务] [我的]                |
+--------------------------------------------------+
```

### 设计说明

- 社区首页需要明显强化 `宠物主体`，而不是只展示用户昵称。
- 推荐、关注、同城、问答四个流必须认知清晰。

## 6. 服务首页

```text
+--------------------------------------------------+
| [城市]               [搜索]                       |
+--------------------------------------------------+
| 服务入口                                          |
| [医院] [寄养] [洗护] [训练] [商城]                |
+--------------------------------------------------+
| 当前宠物推荐                                      |
| 基于年龄 / 体型 / 品类推荐内容                    |
+--------------------------------------------------+
| 附近医院                                          |
+--------------------------------------------------+
| 热门商家                                          |
+--------------------------------------------------+
| 宠物适配商品                                      |
+--------------------------------------------------+
| 我的预约 / 我的订单                               |
+--------------------------------------------------+
| [首页] [宠物] [社区] [服务] [我的]                |
+--------------------------------------------------+
```

### 设计说明

- 服务页要基于当前宠物做推荐，不应做普通目录页。
- 对未开通服务统一使用预留态承接，不允许白屏或空页。

## 7. 家庭共养管理页

```text
+--------------------------------------------------+
| [返回]            家庭共养管理           [邀请]    |
+--------------------------------------------------+
| 当前家庭信息                                      |
+--------------------------------------------------+
| 成员列表                                          |
| - 成员 A / 拥有者                                 |
| - 成员 B / 管理员                                 |
| - 成员 C / 普通成员                               |
+--------------------------------------------------+
| 共享宠物列表                                      |
+--------------------------------------------------+
| 权限说明                                          |
+--------------------------------------------------+
```

### 设计说明

- 家庭共养页的重点不是社交，而是清晰的角色和共享关系。
- 成员对宠物的操作记录后续需要可追踪。
