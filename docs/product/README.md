# Pet App Product Docs

## 文档说明

该目录用于沉淀 `宠物生活管家` 的产品方案母稿，目标是让后续的产品、设计、前端、后端都能沿着同一套文档继续细化，而不是反复从聊天记录里回捞信息。

## 文档结构

1. [01-product-overview.md](./01-product-overview.md)
   产品定位、目标用户、核心场景、主链路、产品原则。
2. [02-information-architecture.md](./02-information-architecture.md)
   完整信息架构、页面清单、模块边界、关键联动规则。
3. [03-prd-core-pages.md](./03-prd-core-pages.md)
   PRD 骨架、核心模块需求、页面级 PRD 全量版。
4. [04-low-fidelity-wireframes.md](./04-low-fidelity-wireframes.md)
   首页、宠物主页、萌宠日常、社区、服务首页等关键页面的低保真线框说明。
5. [05-business-entities.md](./05-business-entities.md)
   产品层业务实体关系、核心字段语义、对象关系与建模规则。

## 当前产品工作名

`宠物生活管家`

## 当前产品定义

一个围绕 `宠物数字档案` 运转的养宠生活平台，覆盖：

- 宠物档案管理
- 健康记录与提醒
- 萌宠日常与成长日记
- 社区内容分享
- 本地服务预约
- 商品购买
- 智能硬件联动

## 使用建议

- 如果要继续细化产品范围，优先改 `01-product-overview.md`。
- 如果要继续拆页面和模块，优先改 `02-information-architecture.md`。
- 如果要进入设计或研发排期，优先扩写 `03-prd-core-pages.md`。
- 如果要开始画 UI 或原型，优先参考 `04-low-fidelity-wireframes.md` 和根目录 `DESIGN.md`。
- 如果要继续梳理业务对象和字段语义，优先参考 `05-business-entities.md`。
