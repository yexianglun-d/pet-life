# 功能完成清单

## 文档目的

该文档用于持续跟踪 `宠物生活管家 / petlife` 的功能建设进度。

要求如下：

- `[x]` 表示当前仓库中已经存在对应实现，并完成基本验证。
- `[ ]` 表示尚未完成，或只停留在设计层。
- 如果某项能力当前策略是“只做占位，不做真实后端”，会在条目后明确标注 `当前预留态`。
- 后续每次功能完成后，直接更新本文档，不再口头记账。

## 当前范围说明

当前项目交付范围为：

- 用户端 App
- 服务端
- 最小可用后台

当前明确延后但仍保留跟踪的范围：

- 商城真实交易后端
- 设备厂商接入
