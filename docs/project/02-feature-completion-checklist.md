# 功能完成清单

## 文档目的

该文档用于按“完整交付标准”持续跟踪 `宠物生活管家 / petlife` 的真实建设进度。

从本次重构开始，本清单不再把“主链路打通”“页面骨架存在”“前后端只完成一半”视为业务域完成。

## 状态定义

- `已完整完成`：当前范围内所需的页面、交互、异常态、服务端接口、状态机、后台治理和必要验证都已到位。
- `部分完成`：已经有真实实现，但仍缺关键功能、关键治理能力、关键异常态，或只完成了某一端。
- `未开始`：尚未进入真实实现，或仍停留在设计、占位、骨架阶段。
- `当前预留`：仅用于用户明确允许延后的范围。

补充说明：

- `[x]` 仅表示该细项本身已经存在实现并完成基本验证。
- `[ ]` 表示该细项尚未完成。
- 一级业务域是否算完成，以“总状态”为准，不以局部 `[x]` 数量判断。

## 延后边界

当前只有以下范围允许按 `当前预留` 处理：

- 商城真实交易后端
- 设备厂商接入与设备事件链路

除以上范围外，`App + 服务端 + 后台` 都按完整交付推进，不再按“先核心可用”记账。
