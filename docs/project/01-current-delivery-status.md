# Current Delivery Status

## 文档目的

该文档用于按“完整交付标准”记录 `PetLife / 宠物生活管家` 当前真实进度。

从本次校准开始：

- 不再把“主链路打通”视为模块完成。
- 不再把“骨架页 / 占位页 / 只跑通前后端一半”的状态记为完成版。
- 除用户明确延后的 `commerce`、`device` 外，其余范围都按 `mobile-app + server + admin-web` 三端完整交付推进。

## 范围基线

当前完整交付范围：

- 用户端 App
- 服务端
- 后台管理端

当前明确允许延后：

- 商城真实交易后端
- 设备厂商接入与设备事件链路

## 当前总判断

当前项目已经完成了大量真实代码和多条业务主链路，但如果按“完整交付标准”判断：

- 非延后范围内，当前没有任何一级业务域可以认定为“全部完善”。
- 绝大多数业务域处于 `部分完成`。
- 当前项目状态应定义为：
  - 已进入正式业务开发阶段
  - 已完成较大规模真实实现
  - 距离完整完成版仍有明显缺口

## 已进入真实开发的业务域

以下业务域已经具备真实代码基础，不再属于纯设计或纯骨架状态：

- 认证与会话
- 当前用户与个人中心
- 家庭共养
- 宠物主档
- 首页驾驶舱
- 健康档案
- 提醒计划
- 萌宠日常
- 成长时间轴
- 社区
- 举报与审核处理

## 仍然存在的主要缺口

### 1. 用户端 App

- 登录增强已补齐验证码发送、倒计时、自动续期和登录失效恢复，但真实短信仍未接入。
- 个人中心仍不完整：设置页、消息中心、通知与权限设置未完成。
- 宠物主档已补齐完整详情、扩字段、删除/归档和无宠物空状态，但后台宠物管理仍未开始。
- 首页已补齐快捷记录、提醒中心、周报、月报，但首页专用聚合接口仍未完成。
- 健康档案仍缺专用表单细化和附件能力。
- 萌宠日常仍缺图片/视频上传。
- 社区仍缺关注流、同城流、问答流、独立发布页、话题页等。
- 服务中心几乎未进入真实页面和业务开发。
- 通知消息整块尚未落地。

### 2. 服务端

- 认证链路已补齐 refresh 与退出登录，真实验证码校验仍未完成。
- 用户资料、通知设置、城市切换等用户能力未完成。
- 宠物删除/归档、更多字段扩展和无宠物空状态已完成，但后台宠物管理仍未开始。
- 健康附件、自动提醒派生、媒体资源接入未完成。
- 服务中心、通知模块、服务商管理、审计日志等仍未完成。
- 第三方能力仍未接入：短信、对象存储、审核、推送、地图等。

### 3. 后台管理端

- 认证仍是本地占位登录，不是真实账号体系。
- 审核中心已接入举报处理，但审计日志未完成。
- 家庭、宠物、健康、提醒、萌宠日常、时间轴、服务商等大量真实运营后台能力未完成。

## 进度记账原则

后续进度统一按以下规则描述：

- `已完整完成`：功能在当前范围内满足完整交付标准。
- `部分完成`：已有真实实现，但仍缺关键页面、关键接口、治理能力、异常态或必要联动。
- `未开始`：仅有设计、占位、骨架或尚未进入实现。
- `当前预留`：仅用于 `commerce` 与 `device`，或用户后续明确指定延后的范围。

详细功能级进度以 `docs/project/02-feature-completion-checklist.md` 为准。
